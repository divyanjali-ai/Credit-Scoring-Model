# Credit Scoring Model 

## Project Overview 
This project uses Machine Learning to predict creditworthiness based on financial and personal information .

## Algorithm Used 
Random Forest Classifier 

## Model Performance 
Accuracy: 92.98%

Precision: 97.52%

Recall: 70.59%

F1 Score: 81.84%
